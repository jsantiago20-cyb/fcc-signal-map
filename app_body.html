How this works

Any US coordinate. Type one in and the map opens on it. Coverage comes from surveys — a circle of sample points harvested in advance around a centre. If your coordinate sits inside a survey that already exists, it loads immediately. If it does not, the page tells you and gives you a one-click way to build one, because the FCC's servers cannot be read from a web page (see below).

Source. Every coverage number comes from /nbm/map/api/mobile/detail/{process_uuid}/{lat}/{lon} — the same endpoint the FCC's own Location Summary sidebar calls. Terrain is USGS 3DEP hillshade; roads, trails and rivers are OpenStreetMap via Overpass; county lines and town centroids are Census TIGERweb.

Why surveys have to be built ahead of time. broadbandmap.fcc.gov sits behind Akamai Bot Manager and returns 403 to any request from another website, so this page physically cannot fetch coverage itself — no amount of client-side code gets around it. A survey is harvested by a real Chrome browser driven from a script, either on your own machine or on a GitHub Actions runner. USGS, Census and OpenStreetMap all allow direct browser access; the FCC is the only one that does not.

What a filled hex means. That a carrier told the FCC it expects service there — modeled propagation, not a measurement. The FCC's thresholds are the bar: 4G LTE at 5/1 Mbps, 5G-NR at either 7/1 or 35/3 Mbps, all outdoor and stationary. In-vehicle and in-building coverage are smaller.

Read the signal filter. Carriers also report the minimum signal strength behind each claim, ranging from −120 dBm to −50 dBm. −120 dBm sits at or below the usable floor for most handsets. Set the filter to −100 dBm and watch how much claimed coverage disappears — that gap is the practical difference between the map and your phone.

Getting around. Scroll or pinch to zoom, drag to pan, double-click to zoom in; the buttons top-left do the same and RST resets. Hover a hex for its full record, click to pin it. Minor town labels appear as you zoom in.

Limits. Each hex is one point sample, not a polygon the FCC published, so edges are accurate to about the survey's spacing. Only the current filing answers this endpoint — older vintages return 403 — so no year-over-year comparison is possible.
